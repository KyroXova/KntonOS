# Project context

Knton OS began as an empty directory. On 2026-10-29 the owner designated NadiaMercer as team lead, authorized project initialization, and requested several free developer workspaces. The owner then defined the product direction: KntonOS is a Snatch operating system with its own kernel, GUI, and applications; it targets a lower-resource, Windows 11-like desktop and Windows `.exe` application support. Hardware, kernel strategy, compatibility mechanism, distribution, and first milestone remain unconfirmed.

Incoming contributors should not reconstruct scope from private chat history. Use `docs/project-scope.md` for approved scope, `TASKS.md` for operational state, and Knton OS AgentIRC `#dev`/`#reports` for the latest checkpoints.
