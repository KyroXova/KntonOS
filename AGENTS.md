# Contributor agreement

This repository uses the coordination system described in `CONTRIBUTING.md`, `TASKS.md`, and `HANDOVER.md`.

Before contributing, refresh `main` when a remote exists, then read the scope, task board, current handover, active claims, unresolved owner questions, and relevant changed paths. Claim only an eligible, unowned task and reserve only the exact files or components needed. Do not infer missing product requirements.

Every contribution updates `HANDOVER.md` and its task card with the actual change, validation, review, remaining work, and released reservations. Meaningful code, security, or risk changes require an independent review before integration. Integrate only through a normal non-force update to `main` after checking the combined tree.

Owner decisions are recorded in `docs/project-scope.md`. `TASKS.md` is the authoritative task and workspace state. These rules do not authorize deployment, external publishing, service disruption, credential use, or scope changes.
